## Present boundaries

- Only existing local SQLite databases; read-only mode is default and read-write is explicit.
- Schema Explorer covers `main` tables, views, indexes, triggers, and available column metadata; TEMP/ATTACH and detailed index/trigger DDL are not yet supported.
- Handles are process-local and not persisted across restarts; schema reads use a global mutex.
- M1 does **not** implement arbitrary SQL execution, query cancellation, result paging, data editing, transactions, or migration UI. Those belong to M2+.
- No `v0.1.0` application release has been accepted.
