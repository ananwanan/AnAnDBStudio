# M2.1 — Monaco SQL editor and multi-tab workbench

**Implementation branch:** `feat/m2.1-monaco-sql-tabs` (based on `dev`).

**Status (2026-11-09):** Implementation complete and **automated CI passed** on `acf303e7ece029168a7dbf87307af87dd324cba9`; manual Windows/Linux GUI acceptance remains pending. Do not mark the entire milestone accepted before GUI evidence.

## Scope

- Add `monaco-editor@0.57.0` (MIT) with locally bundled editor worker and SQL syntax editing; editor code is lazy-loaded only when a query panel mounts.
- Open multiple independently editable SQL drafts from the **新建查询** toolbar action. Dockview owns placement, switching and layout persistence.
- Bind each draft to a selected SQLite connection or `null`. Closed connection handles are never restored; a stale binding is indicated and must be reselected.
- Rename query tabs and preserve draft SQL/title/binding in versioned local WebView storage. Panel close does not delete the draft. **恢复查询** reopens the latest closed draft.
- Restore layouts containing SQL tabs; remove orphaned tabs whose draft data is missing or invalid.
- No SQL execution or result delivery in M2.1. The Run control is deliberately disabled until M2.2.

## Limits and privacy

- Drafts are stored as **plaintext in local WebView localStorage**, not in a database or encrypted storage. Never type passwords, access tokens or other secrets into drafts.
- Autosave is debounced by 300 ms and flushed on `pagehide`. If storage is unavailable, quota is exceeded, or there are more than 50 drafts, an error is surfaced; the open editor contents remain in memory until app exit.
- Saved format is `{version: 1, drafts: [{id, title, sql, connectionId}]}` with per-draft 256 Ki-character and aggregate 1 Mi-character limits.
- Removing or resetting a Dockview panel does not destroy a saved SQL draft. Deleting a draft is an explicit, irreversible in-editor action with a confirmation dialog; native Dockview tab close retains the draft.
- Monaco's local worker must function in Release without remote CDN dependencies, across dark/light themes and Windows IME input.
