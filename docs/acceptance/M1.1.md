# M1.1 — SQLite driver foundation

**Status:** Implemented as a patch; local Windows/Linux checks pending.
**Base:** `dev` after M0 PR #5 (`e3b1f3f`).

## Scope

- Introduce a Tauri-independent `anandb-driver-sqlite` crate.
- Open existing on-disk SQLite files in explicitly selected read-only or
  read-write mode. Do not use `SQLITE_OPEN_CREATE` or `SQLITE_OPEN_URI`.
- Reject missing paths, directories, and invalid database contents.
- Verify `PRAGMA user_version` and explicitly close the connection.
- Keep the connection private; worker ownership, Tauri IPC and UI are M1.2+.
- Use `rusqlite 0.41.1` with `bundled` SQLite for consistent builds.
  `rusqlite`/`libsqlite3-sys` are MIT-licensed; SQLite is public domain.
