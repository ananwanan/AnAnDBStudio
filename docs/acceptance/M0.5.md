## Scope and stage breakdown

Out of scope: SQLite connections, query execution, CRUD, Monaco, AG Grid and remote database drivers.

## M0.5.1 implementation notes

- Rust `src-tauri/src/commands/app_info.rs` exports `get_app_info` with camelCase serialized fields and protocol version 1.
- `src-tauri/src/lib.rs` registers the command; legacy `greet` is kept unchanged for compatibility.
- `src/services/app-info.ts` is the only frontend code that invokes the command; the result is validated as unknown at runtime before being represented as typed `AppInfo`.
- The status bar performs the request only inside Tauri, shows connection success or a bounded failure label, and remains safe in browser preview.
- Unit test cases cover the Rust response, serialization, frontend success/invalid response/incompatible version/transport failure, and the UI indicator.
- No new dependency, database capability, filesystem permission or shell permission was added.
