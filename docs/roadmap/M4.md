# M4 数据编辑

| 阶段 | 交付 | 验证 |
| --- | --- | --- |
| M4.1 | 普通 SQLite 表的行身份、列权限、类型化编辑 | rowid 遮蔽、复合主键、只读、生成列、键盘输入 |
| M4.2 | 标签内修改集、变更预览、离开保护 | 跨页保留，默认值与 NULL，取消新增，提交与放弃 |
| M4.3 | worker 原子提交及冲突报告 | 并发、DDL、约束、SQL 事务互斥、取消与超时 |
| M4.4 | Community 网格编辑及状态反馈 | 选择、焦点、深浅主题、IME、分页回归 |
| M4.5 | 自动化与桌面验收 | Windows/Linux 检查和人工签核后确认 MVP |

同一表的修改在一次 SQLite 写事务中提交。修改集保存首次观察到的完整行和原行身份，提交前重新验证结构，事务内检查原值。部分预览行保留只读。SQL 标签继续使用 M2 查询工作流。具体结果见 [M4 验收](../acceptance/M4.md)。
