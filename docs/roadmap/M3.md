# M3 开发路线

| 阶段 | 交付 | 核验 |
| --- | --- | --- |
| M3.1 | AG Grid Community 只读网格与独立 Dockview 标签 | 表及 SQL 标签并存、重复列名、列宽、行号、深浅主题 |
| M3.2 | SQLite 表结果分页、SQL 结果保留和生命周期 | 分页边界、取消、超时、连接隔离、M2 多语句和写语句行为 |
| M3.3 | 视口增量加载、缓存和跳转 | 验证真实 10 万及 100 万行数据库和快速滚动 |
| M3.4 | Explorer 表入口、刷新、排序、筛选 | 双击和右键、特殊标识符、WITHOUT ROWID、参数绑定 |
| M3.5 | 类型保真、复制和选区导出 | int64 边界、Unicode、NULL、BLOB、CSV/TSV 及平台验证 |

1. 在 Explorer 中连接现有 SQLite 文件，双击普通表或使用右键「查看数据」。
2. 在表标签使用「应用」组合排序和筛选。使用「刷新」读取当前数据，或输入行号跳到深页。
3. 从 SQL 编辑器保留完整结果时，执行后在 Results 选择语句并打开数据标签。
4. 单击选定单元格，使用 Shift+单击或 Shift+方向键扩展选区，再复制或导出。

实现和容量限制见[架构与 IPC](../architecture/M3-data-browser.md)。已运行的验证及待验项目见[验收记录](../acceptance/M3.md)。M4 单独处理行身份、修改集、冲突检测和提交/回滚。
